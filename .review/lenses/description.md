## Lens: what the description claims against what the change does

The reader was not there when the code was written. They have the description, the commits and the diff.

Report a sentence of the description that:

- says the change does something the diff does not show, or names a function, file or type that the diff and the repository do not have;
- uses a name, id or number the reader cannot resolve from the repository or the description itself;
- is true of every pull request in this repository because `AGENTS.md` says so, or repeats what the diff, the commit list, CI or `doc/checks.json` already show.

Do not report wording, tone, length, or anything the description leaves out.

The fix is one of two: delete the sentence, or replace it with the fact from the diff, which you name.
