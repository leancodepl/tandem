# Own AG-UI protocol model behind `AgentConnection`, no dependency on `ag_ui`

Tandem's core has its own small model of the AG-UI wire format (run input, messages, events) and talks to an agent only through the `AgentConnection` seam, with `HttpAgentConnection` (HTTP + SSE) and `ScriptedAgent` for tests. We did not build on the community `ag_ui` Dart package (0.3.0, 2026-06-24), although it is the only Dart SDK listed by AG-UI, because its client turns the first unknown event type into a stream error, drops AG-UI 1.0 fields such as `RUN_FINISHED.outcome`, cannot cancel a run once response headers arrived, never sends the `runId` that ag-ui-adk requires, and exports a `State` typedef that clashes with Flutter. A first-party AG-UI 1.0 Dart SDK was proposed upstream on 2026-10-15 and closed the same day, so the Dart SDK landscape may change; when we adopt or collaborate on a package, it becomes one more `AgentConnection` adapter and nothing else in Tandem changes.
