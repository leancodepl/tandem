# tandem

The runtime behind Tandem, which lets an AI agent work on an existing Flutter screen together with the user over AG-UI: the agent list, the session, `TandemChat` and `ScriptedAgent`. It knows nothing about bloc.

Apps depend on [`tandem_bloc`](https://pub.dev/packages/tandem_bloc), which exports this package. How to use it is in the [main README](https://github.com/leancodepl/tandem#readme).
